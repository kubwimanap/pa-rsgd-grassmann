# PA-RSGD on the Grassmann manifold

Code and data for the article

> P. Kubwimana, B. Prabhakar Reddy, J. M. Mkenyeleye.
> **Riemannian Stochastic Gradient Descent on the Grassmann Manifold under Interacting Rounding,
> Stochastic-Gradient and Retraction Errors.** Submitted, 2026.

The repository implements Riemannian stochastic gradient descent (RSGD) on the Grassmann manifold under three
simultaneous perturbations (finite-precision rounding **N**, minibatch noise **S** and inexact retractions **G**),
the perturbation-aware step-size rule **PA-RSGD** (Algorithm 1), and every experiment behind the tables and
figures of the article.

## Contents

```
parsgd/                    library
  arith.py                 simulated RN / SR rounding to t bits, binary16, bfloat16,
                           low-precision accumulation, native XLA kernels (optional)
  problems.py              synthetic, spiked (n = 10^4), robust energy, F2 extension,
                           UCI optical digits, Hopkins 155 loader
  algorithms.py            perturbed RSGD (eq. (4)), retractions (surrogate (3), none,
                           periodic, Newton-Schulz, landing), PA-RSGD, RSVRG
  bounds.py                a-priori constants, drift bounds (Theorem 1),
                           convergence floors (Theorem 3), stability edge (14)
experiments/               one script per group of tables and figures
results/tables/            CSV output of every experiment
results/figures/           PNG and PDF figures
data/                      data notes (Hopkins 155 must be supplied by the user)
PAPER_NUMBERS.md           every number quoted in the text of the article, with its source
COMPARISON.md              values of the earlier manuscript draft next to the values produced here
```

## Installation

```bash
git clone https://github.com/kubwimanap/pa-rsgd-grassmann.git
cd pa-rsgd-grassmann
pip install -r requirements.txt
pip install "jax[cpu]"        # optional, only for the native-kernel rows of Table S5
```

Python 3.9 or later.

## Running

```bash
python experiments/run_all.py --quick     # small settings, about 10 minutes
python experiments/run_all.py             # full settings of the article, about 2-3 hours on 2 cores
python experiments/ablation.py            # any single experiment
python experiments/ablation.py --workers 8
```

Every script accepts `--quick` and `--workers N`. All random seeds are fixed, so a run reproduces the CSV files in
`results/` exactly on the same platform.

## Data

* **Synthetic, spiked and robust problems** are generated by the code from fixed seeds.
* **UCI optical digits** are the copy bundled with scikit-learn (no download), rescaled so that the leading eigenvalue
  of the covariance is 4 (gap between the 5th and 6th eigenvalues about 0.23).
* **Hopkins 155** is not redistributed. Place `1R2RC_truth.mat` (and, if available, `1R2RCR_truth.mat`) as described
  in [`data/README.md`](data/README.md), or set `PARSGD_HOPKINS=/path/to/hopkins`. Each motion gives one PCA problem
  (centred trajectories, p = 2). The results in `results/` use 1R2RC. Without the files, the Hopkins columns are
  reported as "not run".

## Notes on the implementation

* **Arithmetic.** Rounding to t significand bits is simulated after every arithmetic result (round-to-nearest with
  u = 2^-t, or unbiased stochastic rounding with u = 2^(1-t)); the projected direction is evaluated in the order of
  Lemma 3. `Arith(fmt="binary16")` uses the IEEE binary16 format, `accumulate="low"` rounds every partial sum of a
  matrix product, and `NativeArith` calls XLA's reduced-precision matrix kernels through JAX.
* **Stationary quantities** are averaged over the last 20% of the recorded iterations; diverged runs are assigned the
  maximal error sqrt(p).
* **A-priori bounds** (`bounds.py`) use only the data model at the solution and the corrected rounding constant of
  Lemma 1, c_r = 2 sqrt(p) (1 + gamma kappa_star).
* **PA-RSGD** follows Algorithm 1: the outer minimum with eta_max and the drift monitor enforce the hard constraints of
  the window (21); eta_S, eta_K and eta_N are candidate steps inside the window, and the largest is taken.

## Relation to the manuscript numbers

The tables, figures and every number quoted in the text of the article (version 5 onwards) come from the files in
`results/`; `PAPER_NUMBERS.md` lists the quoted numbers with their sources. [`COMPARISON.md`](COMPARISON.md) records
how these values differ from an earlier draft that was produced with different scripts.
